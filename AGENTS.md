# Repository Guidelines

## MANDATORY: Use td for Task Management

You must run td usage --new-session at conversation start (or after /clear) to see current work.
Use td usage -q for subsequent reads.

## Project Structure & Module Organization
- `entrypoints/` contains browser extension entry points (background, content, popup, etc.).
- `components/`, `composables/`, `modules/`, and `utils/` hold Vue UI, shared hooks, feature modules, and utilities.
- `styles/` and `assets/` contain Tailwind-driven styles and static assets; `public/` holds extension-static files.
- `locales/` stores i18n resources.
- `tests/` contains Playwright e2e and HTML fixtures; `.output/` is generated by WXT builds.

## Build, Test, and Development Commands
- `pnpm install` installs dependencies.
- `pnpm dev` runs the Chrome dev build; `pnpm dev:edge` and `pnpm dev:firefox` target other browsers.
- `pnpm zip:beta` and `pnpm zip:prod` create packaged builds; output is in `.output/`.
- `pnpm build:prod` creates a production build without zipping.
- `pnpm check` runs type-checking (`vue-tsc`) and linting.

## Coding Style & Naming Conventions
- TypeScript/Vue without semicolons and with 2-space indentation.
- Prefer `const` over `let`, never `var`.
- Naming: `camelCase` for functions/variables, `PascalCase` for classes and Vue components, `UPPER_CASE` for constants.
- Vue: Single-File Components, multi-word component names, Composition API with `<script setup>`.
- Linting via `eslint`; TailwindCSS conventions for styles.

## Testing Guidelines
- Unit tests use Vitest: `pnpm test:unit`.
- End-to-end tests use Playwright: `pnpm test:e2e`.
- Keep tests close to the feature and name files clearly (for example, `feature-name.spec.ts`).

## Commit & Pull Request Guidelines
- Commit messages: present tense, imperative mood, 72-char first line, optionally prefix with an emoji (e.g., `:bug: Fix crash`).
- Reference issues after the first line when relevant.
- PRs: use the template, avoid issue numbers in the title, include screenshots/GIFs when UI changes, add tests and docs, and ensure files end with a newline.
